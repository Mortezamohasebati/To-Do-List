## 🖥️ این چیه؟

یک **اپلیکیشن دسکتاپ مدیریت وظایف فارسی** که کاملاً با Python نوشته شده. هیچ مرورگری، هیچ Electron‌ای، هیچ دیتابیسی لازم نیست — فقط Python خالص، PyQt5، و یه فایل `tasks.json`. این اپ فارسی بلده، تقویم شمسی داره، و توی هر دو حالت تاریک و روشن عالی به نظر می‌رسه.

همه کد توی یه فایل `main.py` خلاصه شده — ۱۰۸۵ خط با مدل داده درست، معماری signal/slot در PyQt5، ویجت‌های سفارشی قابل‌استفاده‌مجدد، و یه موتور تم دو پالتی کامل.

## ✨ ویژگی‌ها

| | ویژگی | جزئیات |
|:---:|---|---|
| 🌙 | **تم تاریک / روشن** | تغییر کامل تم با یه کلیک — هر ویجت، کارت، و دیالوگ فوری رنگ عوض می‌کنه |
| 📅 | **تقویم شمسی (جلالی)** | انتخاب‌گر تاریخ/زمان فارسی با spinbox برای سال · ماه · روز · ساعت · دقیقه |
| 🏷️ | **۴ دسته‌بندی هوشمند** | شخصی · فوری · کار · ایده — هر کدوم با رنگ اختصاصی کامل |
| 🎨 | **رنگ سفارشی کارت** | انتخاب‌گر رنگ برای هر وظیفه با `QColorDialog` بومی Qt و کنتراست متن خودکار |
| ⚡ | **افزودن سریع از سایدبار** | عنوان رو بنویس، دکمه دسته رو بزن — وظیفه فوری اضافه می‌شه |
| ✨ | **دیالوگ افزودن پیشرفته** | مودال کامل: عنوان، توضیحات، سررسید شمسی، دسته‌بندی، رنگ کارت |
| 📊 | **پنل آمار زنده** | شمارنده‌های لحظه‌ای: کل · انجام‌شده · در انتظار · فوری |
| 📈 | **نوار پیشرفت گرادیانی** | درصد تکمیل کلی با گرادیان بنفش → سبز |
| 🔍 | **جستجوی لحظه‌ای** | فیلتر فوری تمام وظایف همزمان با تایپ |
| ⇅ | **مرتب‌سازی** | مرتب‌سازی بر اساس تاریخ سررسید یا دسته‌بندی با یه کلیک |
| 💾 | **ذخیره‌سازی JSON** | همه داده‌ها در `tasks.json` ذخیره می‌شن — بدون راه‌اندازی، بدون مایگریشن، بدون سرور |
| 🖥️ | **لانچر ویندوز** | `RUN_TO.bat` برای اجرای دابل‌کلیکی روی ویندوز |

## 🏗️ معماری پروژه

```
📦 To-Do-List/
 ├── 🧠 main.py        ۱۰۸۵ خط · PyQt5 + jdatetime
 │    ├── THEMES {}         پالت رنگ تاریک و روشن
 │    ├── Task              مدل داده (to_dict / from_dict)
 │    ├── ShamsiDatePicker  ویجت سفارشی تاریخ/زمان جلالی
 │    ├── TaskWidget        کارت وظیفه (QFrame + سیگنال‌ها)
 │    ├── TaskDialog        دیالوگ افزودن / ویرایش
 │    ├── StatsWidget       پنل آمار ۴ شمارنده‌ای زنده
 │    ├── SidebarWidget     پنل ناوبری سمت چپ
 │    └── TodoApp           QMainWindow — همه چیز رو کنار هم می‌ذاره
 ├── 💾 tasks.json     ذخیره‌گاه محلی خودکار
 └── 🚀 RUN_TO.bat     لانچر یک‌کلیکی ویندوز
```
